# 50-论文 · LaTeX 小论文

本目录是《生物信息学》课程项目的**独立小论文**版本：用 LaTeX 把项目的完整方法与结果
写成一篇符合会议/期刊格式的论文，并与实验报告**逐位一致**（由 `95_论文数字终审.py` 自动保证）。

## 文件

| 文件 | 说明 |
|---|---|
| `main.tex` | 论文源文件（中文正文，ctexart + xelatex 编译） |
| `references.bib` | 参考文献（20 条，BibTeX） |
| `main.pdf` | 编译产物（18 页，A4） |

## 编译

```bash
cd 50-论文
xelatex main.tex      # 第 1 遍：生成 aux/bbl 骨架
bibtex  main           # 生成 main.bbl（参考文献）
xelatex main.tex      # 第 2 遍：插入引用与页码
xelatex main.tex      # 第 3 遍：交叉引用收敛
```

用 **XeLaTeX**（不要用 pdfLaTeX）——中文需要 ctex 宏包与系统字体。
需要 TeX Live 完整版（含 ctex、natbib、booktabs 等）。

## 图片路径

论文用 `\graphicspath{{../30-可视化/figures/}}` 引用十张图，
因此**必须从本目录编译**（保持目录结构），否则找不到图。

## 与报告的关系

- 论文 = **对外发布版本**（结构化、文献引用完整、18 页）
- 实验报告 = **对内交付版本**（含全部附录 A–E、逐项算法说明、59 页）

两者数字**必须一致**。项目里有两个独立的终审脚本：

| 脚本 | 检查对象 | 断言数 |
|---|---|---|
| `20-分析/07_终审核对.py` | `40-报告/01-实验报告.md` | 239 |
| `20-分析/95_论文数字终审.py` | `50-论文/main.tex` | 103 |

两个脚本**各自独立从结果文件取真值**（不互相引用），因此报告错了论文不会跟着错。

## 论文结构

```
摘要 → 1 引言 → 2 相关工作 → 3 数据与方法 → 4 结果 → 5 讨论
     → 6 结论 → 参考文献 → 附录 A 算法流程 / B 关键参数 / C 补充图表
```

其中 §3.9 与 §5.3 专门写了本项目**自己踩过的七个坑**（Spearman 同义反复、PCA 零假设置换对象、
成分数据秩亏、`n_dbs` 语义、宏 F1 幽灵类、numpy argmax 遇 NaN、双单尾右尾退化），
这些是本项目最有方法学价值的产出。
