## 十三个必须注意的坑

> 这 13 条都是本项目**真实踩过并已修好**的，每一条都在报告 2.6 节有对应记录，
> 并由 `07_终审核对.py` 自动化拦截复发。

### 1. 基因名不是符号，是 Ensembl ID

`var` 的索引是 `ENSG00000223972` 这种，基因符号在 `var['feature_name']`，
而且 1,316 个（2.2%）带 `_ENSG` 后缀（同名基因去重时加的）。
`ts_io.py` 的 `symbols()` 已经处理了。**直接拿 `var_names` 去匹配年龄表，匹配率会是 0。**

### 2. `var/feature_name` 是 Group，不是 Dataset

这个 h5ad 的 `feature_name` 是个 HDF5 **Group**（内含 `categories` + `codes`），
不是普通字符串数组。直接 `h["var"]["feature_name"][:]` 会报
`TypeError: Accessing a group is done with bytes or str`。
`obs` 里每一列同样可能是 Group 也可能是 Dataset，**两种都要试**。

### 3. X 已经是归一化过的

`X` 是 float32、最大 10.0 的 log 归一化值；`raw.X` 才是原始 UMI 计数。
脚本统一用 `raw.X` 自己归一化。**对 X 再 `normalize_total + log1p` 就是归一化两次。**

### 4. 分类必须按供者划分

15 个供者（TSP1–TSP15）。同一个人的细胞如果同时进训练集和测试集，
模型会背下"这个人的表达特征"，准确率虚高到 0.99。
`05_监督分析.py` 按 `donor_id` 划分，**不要改回按细胞随机划分**。

### 5. 年龄层是 16 层，不是 19 层

Trigos et al. 2017 用的是 16 层方案，和网上常见的 Domazet-Lošo 19 层
（多出 Deuterostomia / Vertebrata / Tetrapoda）**不能混用**。
16 个层名写在 `common.py` 的 `STRATUM_NAMES`。

### 6. `NumDBsContributing` 是分母，不是支持数（踩过最贵的一次）

Liebeskind 2016 的共识表里，`n_dbs` 表示**参与投票的算法总数（分母）**，
不是"支持该年龄层的算法数"。真正的共识度要自己算：
**`mode_share = 最优势层占比`**，支持数 = `round(mode_share × n_dbs)`。

本项目最初用 `--min-dbs 10` 想筛"高置信"基因，实测
**corr(n_dbs, mode_share) = −0.128（负相关）** —— 方向正好反了：
参与算法多的基因往往分歧也大。**改成 `--min-share 0.8` 才是正确的高置信过滤。**

> 同一个"置信度"直觉，如果照搬字面含义，会让筛选结果与预期完全相反。
> 这类错误不报错、只是结果悄悄变差，只能靠交叉验证发现。

### 7. 方法本身有已知偏差（且本项目证实了它）

Moyers & Zhang（2015, 2017, 2018）用模拟证明 phylostratigraphy 会系统性
**低估**基因年龄，且误差非随机（短序列、快速演化基因更易被判年轻）。

本项目做六件应对：
- `02_构建年龄表.py` 输出**双来源一致性**（Spearman ρ=0.70，8 个粗类别的中位层号完全单调、零违反）
- `03` 剔除命中率低的 S15/S16 后重算 TAI（**Spearman ρ=0.9883、Kendall τ=0.9518**，按索引对齐算）
- `05 --min-share 0.8` 只用高共识基因重跑（905 个特征），**S8、S10 富集、S2 耗竭**
- `05 --min-length 100` 只用蛋白长度 ≥100 aa 的基因重跑（**2,405 个基因**），
  **S1、S8、S9、S10、S11、S14 富集、S2、S4 耗竭**，方向与 A 组完全一致
- ✅ **直接证实了该偏差确实存在**：层号 vs 短蛋白占比 **Spearman ρ = +0.871**（p<0.001），
  老层 S1–S4 平均短蛋白占比 **1.30%**，年轻层 S13–S16 平均 **14.23%**（相差 11 倍）——
  这正是 Moyers & Zhang 描述的「年轻偏倚」，所以剔除短蛋白是**必要的修正**而非锦上添花
- 全部显著性判定改用 **BH-FDR 校正后的 q 值**（96 次检验，富集与耗竭方向分别校正）

### 8. HDF5 的 dataset 数据不在你以为的字节偏移上

chunked dataset 的数据位置由对象头和 B-tree 决定，**不是「元素序号 × 元素大小」**。
踩过一次：按字节偏移读 `raw.X/data`，拿到的是一堆垃圾字节（`max=nan`）。
正确做法是让 h5py 自己定位（`dset[a:b]`，它会自动解压 gzip），
再用 `dset.chunks` / `dset.id.get_chunk_info*()` 规划要读哪些 chunk。

### 9. 超几何检验要用双单尾，不能只看右尾

右尾 p ≈ 1 只说明"**没有证据表明富集**"，不能推出"回避"。
`05` 现在同时算 `p_enrich = sf(k-1)` 与 `p_depletion = cdf(k)`，
富集与耗竭各配各的检验。修正后 S2 的耗竭 p = 2.4×10⁻¹⁷ 才真正站得住。

### 10. `numpy.argmax` 遇 NaN 会返回 NaN 的位置

`se.values.argmax()` 在数组含 NaN 时返回的是 **NaN 所在下标**，不是最大值下标。
本项目曾因此把「标准误最大（0.1323）」标到了一个 **SE 根本算不出来的类型**（n=1）头上，
数值与标注对不上号。**pandas 的 `.max()` 跳过 NaN，`.idxmax()` 也跳过，numpy 的不跳过。**
涉及"取最大值对应的标签"时一律用 `df.dropna().idxmax()`。

> 这类错误不会让脚本报错，只会让报告里的数字张冠李戴——已由 `07_终审核对.py` 自动化拦截。

### 11. Spearman 相关可能是个同义反复

`spearmanr()` 对 pandas Series 是**按位置**取值的，不是按索引。
如果两列各自已按同一指标升序排过序，位置秩相关**恒等于 +1**——
本项目最初报告的"ρ = 1.0000、τ = 1.0000、排序完全不变"其实是这个恒等式，不是发现。
实测复现：两列独立随机数各自升序后做位置秩相关，500/500 次都算出 ρ = 1.0。
修正为**按索引显式 `reindex` 对齐**后，真实值为 **ρ = 0.9883、τ = 0.9518**
（141/177 个类型名次有变化，最大位移 88 位）。

### 12. PCA 的零假设必须打乱「特征」，不能打乱「样本」

PCA 分解的是 **16 个特征之间的协方差结构**。置换「细胞类型」这一行**不改变任何一行的 16 维取值**，
所以行置换的零假设与真实数据完全相同——本项目最初就是这么写的，
算出来基线 61.9% = 真实 61.9%，z = 0，**零假设彻底失效还毫无察觉**。

正确做法是**逐列打乱**（每个年龄层内部重排，保留边际分布、破坏层间共变）。
本项目进一步加了**第三条基线**：16 层占比是**成分数据**（行和恒为 1），
协方差**秩亏到 15**，所以再补一条**同秩的 Dirichlet 成分基线**（29.03% ± 0.68%）。
三条基线：逐列打乱 27.05% ± 0.74%、独立正态 27.61% ± 0.72%、Dirichlet 29.03% ± 0.68%，
真实值 61.9% 超出 **z = 47.0 / 48.3** 个标准差。

> 另外：n=177 / d=16 的有限样本效应会让基线远高于理论值 18.75%（实测 27%），
> 所以**基线必须用同规模样本生成**，不能拿理论值当基线。

### 13. 「剔除 595 个」这种总数必须拆开，否则会把修正力度夸大 5 倍

检验 C 剔除的 595 个基因里，只有 **117 个是真正的短蛋白（<100 aa）**，
另外 **478 个是压根查不到蛋白长度的基因**（UniProt 符号与年龄表不一致）——
其中 **477 个本来就没有年龄注释**，在 A 组里**从未进入过富集检验**，只有 1 个例外。

不拆开就会写成"剔除 595 个短蛋白"，让人以为修正力度是实际值的 5 倍。
真相是：真正从富集检验背景中移除的只有 **118 个**（117 短蛋白 + 1 无长度但有年龄注释），
背景从 **2,523 降到 2,405**；其余 477 个基因在 A 组里就没有年龄层。

> 教训：**任何"过滤掉 N 个"的陈述都要能拆到每一类的原因**。
> 本项目现在把逐基因去留明细落盘到 `filtered_genes_shortprot.tsv`，
> 并由终审脚本断言 117 / 478 的拆分与 595 的总数自洽。

## 三种可能的结果，每种都有价值

| 结果 | 含义 | 本项目实际 |
|---|---|---|
| Top 基因显著偏向老基因 | 细胞身份由深层保守基因定义 | ✗ 相反 |
| Top 基因显著偏向年轻基因 | 细胞身份由新近演化的基因区分 | ✅ **正是这个** |
| 没有显著偏向 | 细胞身份与基因年龄无关，是纯调控差异 | ✗ 排除 |

同理聚类 ARI = 0.211 落在弱相关区间，说明"年龄构成不足以单独定义细胞类型，
但确实携带谱系信息"——这也是干净的有效结论，照实写。
